## Правила и принятые решения

- Не удалять код/файлы без разрешения. Обновлённое приложение устанавливать при подключённом доступном телефоне; без удаления приложения, очистки пользовательских данных и неподтверждённого понижения версии.
- Обычные изменения — стабильные релизы с уведомлением. Бета — экспериментальные функции, а не канал по умолчанию. Нельзя считать только GitHub Release выполненной рассылкой: нужны каталог приложения и проверка push-очереди. Серверная отправка не доказывает доставку каждому телефону.
- Не добавлять платные сервисы/ИИ без понятной задачи и оценки. Пользователь явно выбрал выпуск без подключения нового источника массовых офлайн-карт.
- Не приписывать серверу недоступные критерии безопасности, тишины, высот и трафика. Не выдавать отсутствие данных за нулевые значения.
- Шлейф выбирает владелец аккаунта; друзья видят его выбор. Зритель может скрыть шлейфы, но не задаёт чужой рисунок.

## Открытые зависимости — не выдавать за готовые функции

1. `OFFLINE_TILE_URL` не настроен. Массовая загрузка отключена по выбору пользователя. Есть ограниченная реализация области маршрута: 13–16 масштабы, максимум 8000 тайлов, проверка фактического кэша; это прямоугольная область, не оптимизированный коридор и не карта всей страны.
2. Автономного дорожного движка/графа нет. Пересчёт и подключение впереди требуют интернета. Для сегментированного трека и обязательных остановок автоматическое подключение впереди отклоняется; нужно ручное изменение пути.
3. Текущий сервер не применяет запросы «тише», «меньше подъёмов/остановок». Высоты могут быть неизвестны; 0 не доказывает отсутствие подъёмов.
4. Overpass: последние живые пробы дали 406 и таймаут. Качество/доступность данных в городах не подтверждены. Поиск ограничен 2000 точками пути и 500 результатами; действия доступны по фактическому режиму редактирования маршрута. Сбой не равен отсутствию мест.
5. Телефон: нет подтверждённых полевых замеров расхода батареи, восстановления после process-kill, прослушивания голоса и одновременной работы на двух устройствах. При подключении проверить именно текущий APK/сценарий.
6. Прямые интеграции часов/велокомпьютеров, новый смысловой поиск и дополнительные серверные сервисы не внедрены; сначала оценка пользы, SDK/стоимости и данных. Геопозиция друзьям и основные статистические возможности уже есть.
7. Российского сервера для пользовательской аналитики ранее не было: не включать новую отправку координат/телеметрии под видом улучшения приложения без проверки текущего решения и отдельного основания.
