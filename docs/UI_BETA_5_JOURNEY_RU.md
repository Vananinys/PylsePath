# UI Beta6: совместный заезд и клубы

31.10.2026. Запрос пользователя — выполнить шесть предложенных улучшений в отдельной UI Beta. Контрольная точка до работы14ef224, исходный проверенный APK87.

## Поведение

- Клуб — постоянный состав; заезд — отдельный сеанс с новыми приглашениями. Обнаружено, что прежний group_action('create') возвращал старую комнату организатора даже при replace=true. Новый UI API действительно создаёт новый заезд; прежние участники не переносятся. Выход/новый заезд организатора передаёт управление оставшемуся участнику; его личная запись не останавливается. Последний выход закрывает пустой заезд. Повтор после неопределённого сетевого результата использует один request_id и не создаёт ещё один заезд.
- В ожидании отдельно показаны приглашённые и присоединившиеся. Серверные статусы: ожидает/принял/отказался/отменено/истекло/заезд завершён. Получатель может отказаться, отправитель — отменить; чужое приглашение принять нельзя. Вход по коду тоже является собственным действием получателя. Старый API также не принимает уже отклонённое приглашение.
- У участников видны подготовка, самостоятельная отметка «Настройки готовы», старт/пауза/завершение, прогресс и возраст устаревших данных. Членство не запускает запись.
- Подготовка: активность/транспорт/маршрут и компактный блок участников на одном экране; список приглашений раскрывается. Дополнительные параметры отдельно. Ручной старт сохранён. Завершивший свою тренировку не может повторно запустить её в том же заезде: нужен новый заезд либо самостоятельная тренировка. Локальная отметка завершения сохраняется на аккаунте даже при запаздывающем сервере.
- Завершение: «Сохранить тренировку» оставляет человека для просмотра результатов; «Сохранить и завершить участие» завершает только его участие. После локального сохранения показаны собственный результат и состояние остальных на момент сохранения, переход к детали/участникам/карте. Если сеть не подтвердила статус или выход, сохранённая тренировка не выдаётся за потерянную/стоящую на паузе; показана возможность повтора. Смена заезда на другом устройстве не подмешивает новый состав в итог старого.
- Главная клуба: ближайшее будущее событие, непрочитанные сообщения, участники, приглашение на заезд и настройки уведомлений. Сообщения читаются при открытии вкладки чата, а не при просмотре главной. Список клубов обновляет счётчики на активном экране.
- Режимы уведомлений клуба: «Все сообщения и приглашения», «Только приглашения на заезды и события» (по умолчанию), «Выключены». Настройка хранится на сервере у текущего участника. Отдельный worker отправляет FCM только зарегистрированным клиентам UI Beta с повторной проверкой членства, режима и владения токеном. Текст закрытых сообщений не помещается в системный push. Есть очередь, повтор, ограничение попыток и квитанции по хешу токена. Обычные клиенты поддержку этих уведомлений не регистрируют.
- Нажатие уведомления открывает нужный чат/события клуба после проверки доступа. Действуют разрешения ОС; доставка на конкретный телефон не следует из одного наличия worker.

## Модули и сервер

- Новые UI: group_journey_panel, group_ride_result_sheet, club_overview. Обновлены группа/приглашения/подготовка/завершение карты, клубы и push_service.
- UI API: group_ui_snapshot/group_ui_action, отдельный флаг uiFlow только у UI Beta (в старых transport-тестах выключен по умолчанию). Старые API сохранены. declined_at в приглашениях, внутренняя таблица идемпотентности. Исходники: group_ui_journey_schema → group_ui_retry_schema → group_ui_sender_status_schema → group_ui_safe_switch_schema.
- Клубы: club_notifications_schema → club_push_devices_schema → club_ui_safe_switch_schema. Внутренняя реализация club_action_base защищена от прямого вызова клиентом; public invoker-wrapper вызывает проверяющую функцию. club_push_outbox/deliveries/devices с RLS и запретом клиентских чтений/записей; claim только service_role; cron club-push-retry.
- Edge Function send-club-push version2 active, собственная проверка webhook-secret (verify_jwt=false только для внутреннего webhook), существующие серверные Firebase/Vault настройки не выводились и не менялись. Исходник docs/releases/functions/send-club-push/index.ts; используется прежний общий OAuth helper.
