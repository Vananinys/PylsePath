# PulsePath UI Beta 1.16.9-ui-beta.13+115

Android arm64, отдельный пакет com.pulsepath.app. Флаги UI_BETA,
E2EE_MESSAGING и E2EE_TEST_CHAT включены.

Для E2EE push клиент загружает сообщение через авторизованный запрос,
расшифровывает локальным ключом и показывает текст либо обозначение стикера.
Открытый текст не добавляется в серверный push. Проверяются текущий аккаунт,
отправитель, получатель, успешность расшифровки и статус прочтения. Текст
не сохраняется в payload действий уведомления. На Android сохранена private
visibility; доступность текста на экране блокировки зависит от настроек ОС.

Без ключа, сессии или сети показывается нейтральная заглушка. Для загрузки
выделено 8 секунд. Data-only доставка может задерживаться ограничениями ОС;
после принудительной остановки приложения фоновая доставка не гарантируется.
Доработка относится к Android: iOS Notification Service Extension не добавлен.
Остальные ограничения и известные вопросы аудита beta12 сохраняются.
