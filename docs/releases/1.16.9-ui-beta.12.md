# PulsePath UI Beta 1.16.9-ui-beta.12+114

Отдельный com.pulsepath.app. Сборка: UI_BETA=true, E2EE_MESSAGING=true,
E2EE_TEST_CHAT=true, Android arm64. Обычный APK не заменяется.

## Реальная переписка

- Личный ChatScreen отправляет текст и стикеры как crypto_box-конверт для
  отправителя и получателя; body на сервере содержит только нейтральную заглушку.
- Поддержаны Realtime, цитирование, правка своих защищённых сообщений и прочтение.
- Замок отмечает E2EE, специальный значок — невозможность расшифровки. Старая
  история и системные карточки без замка остаются незашифрованными.
- Оба собеседника должны открыть эту UI Beta: она создаёт и регистрирует ключ.
  Если ключа собеседника нет, отправка отклоняется без открытого fallback.
- Первое защищённое сообщение блокирует открытые записи в этот диалог на сервере,
  включая старые клиенты. Другие диалоги не переключаются автоматически.
- Приватность → Ключи реальной переписки, либо кнопка ключа в чате: личный ключ
  восстановления и SHA256-отпечатки. Личный ключ серверу не передаётся, резервная
  копия зашифрована. На Android экран ключей закрыт от снимков/записи экрана.
- Новые кэш и черновики беты сохраняются в защищённом хранилище; прежние данные
  не стираются. Зарегистрированные ключи и сохранённые отпечатки работают офлайн.
- Push для E2EE содержит нейтральное уведомление без текста и стикера.

## Ограничения эксперимента

Вложения (фото, голос, видео, маршруты) блокируются до подключения их шифрования.
Клубные/групповые чаты и системные карточки этим выпуском не переводятся на E2EE.
Поиск в защищённом чате выполняется на устройстве среди последних сообщений.
Crypto_box не обеспечивает прямую секретность при утечке личного ключа. Проверка
первого ключа — TOFU: сверять отпечатки по независимому каналу. Это не Signal и
не заявление о полной конфиденциальности всех данных приложения.

## Проверка

Реальные HTTP-запросы и Realtime между двумя созданными QA-аккаунтами:
шифротекст без открытого дубля, ответ/правка/прочтение, восстановление на новом
клиенте, отказ третьему аккаунту, блокировка открытого downgrade и изменения
шифротекста получателем. Учётные данные и тестовые приватные ключи остаются
в локальных файлах вне Git. Одноразовый provisioning endpoint закрыт (410).
CI дополнен офлайн-тестами реального ChatService и приватности push.

В одном повторе сетевого теста был тайм-аут Realtime (30 с); следующий прогон
прошёл. Причина не установлена, это ограничение проверки беты.
