# PulsePath UI Beta 1.16.9-ui-beta.11+113

Отдельное приложение com.pulsepath.app. Обычный PulsePath не заменяется.
Сборка: UI_BETA=true, E2EE_TEST_CHAT=true. В обычной сборке пункт теста скрыт.

## Что добавлено

Настройки → Приватность → Тест шифрования · эксперимент.
Локальная лаборатория Алисы и Боба: ввод тестовых сообщений, шифрование
libsodium crypto_box для каждого получателя, расшифровка и просмотр конверта.
Тестовые ключи сохраняются в защищённом хранилище отдельно по аккаунтам.
Проверки подмены ID/диалога/шифротекста и контейнера восстановления доступны
по кнопке. Экран прокручивается и рассчитан на крупный шрифт.

## Границы беты

Это локальный тест на одном устройстве. Он не использует реальные переписки,
не отправляет сообщения через сервер и не подтверждает защиту обычных чатов.
Сетевая доставка, несколько устройств, групповой состав, медиа, push,
миграция истории и восстановление реальной переписки ещё не интегрированы.
Crypto_box не обеспечивает прямую секретность при утечке личного ключа.
Вводить только тестовые фразы. Реестр ключей из docs/e2ee_identity_schema.sql
не применяется при выпуске этой беты; серверные права чатов не меняются.
