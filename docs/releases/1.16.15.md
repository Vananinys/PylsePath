# PulsePath 1.16.15 (125)

Исправлены уведомления и задержки мессенджера:

- При открытии диалога во время инициализации уведомления или ожидания предпросмотра уведомление подавляется. Видимый диалог отслеживается при переходах между экранами и сворачивании приложения.
- Текст и realtime-события отображаются без ожидания подписанных ссылок на вложения. Превью уведомлений и списка диалогов не запрашивают ссылки на медиа.
- Фотографии и постеры автоматически загружаются при появлении на экране. Просмотренные изображения сохраняются между запусками в кеше с разделением по аккаунтам; временный токен не меняет ключ одного объекта. Ограничения: 256 МиБ и 600 объектов. Повторы ограничены; ручная загрузка остаётся доступной.
- Действующие ссылки используются повторно, одновременные запросы одного объекта объединяются. При смене аккаунта результат старого запроса не возвращается новому аккаунту.
- Последние сообщения диалогов получаются пакетным RPC с сохранением RLS, без пропуска тихих диалогов. Для 20 диалогов с фото — один запрос превью вместо 40 запросов сообщений и подписей. Счётчики и друзья загружаются отдельно.
- Входящее сообщение обновляет соответствующий диалог; список сообщений строится лениво со стабильными ключами.

Проверка: 63 целевых Flutter-теста прошли. Статический анализ затронутых файлов не выявил ошибок и предупреждений; остались замечания уровня info. RPC установлен и проверен под синтетическим authenticated-пользователем: чужие сообщения не возвращаются, анонимный вызов запрещён, SECURITY INVOKER и RLS сохранены.

Существующие переписки, черновики и очередь сообщений сохраняются. Отдельное приложение UI Beta этим APK не обновляется и может независимо показывать свои уведомления. Реальная доставка push между двумя аккаунтами и FPS длинной истории на физическом устройстве не измерялись.
