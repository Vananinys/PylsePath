# UI Beta 1.16.9-ui-beta.14+116

Проверка аудита GLM: объединены исправления нейтрального уведомления при ошибке ответа и подсказки об обновлении для защищённых диалогов. Сессия Supabase переносится из SharedPreferences в FlutterSecureStorage с проверкой записи; история и ключи не очищаются. Foreground и background используют одинаковое хранилище. Web сохраняет штатный адаптер.

На сервере отозван подтверждённый TRUNCATE у authenticated; guard сериализует пару одним bigint advisory lock и требует READ COMMITTED для записи, проверяет карточку по настоящему приглашению, поездке и организатору. Предложение GLM с двумя bigint было неисполняемым. Права чтения/удаления и storage проверены по действующим политикам. Тесты guard на временных таблицах исполняются внутри откатываемой транзакции; конкурентный прогон двух соединений пока не выполнен.

Локальный Maven требует явного Gradle-флага; Gradle wrapper проверяет официальный SHA256. Видимый текст входящего push сохранён по требованию пользователя.

Ограничения: crypto_box v1 остаётся без forward secrecy, device keys и ротации; смена recovery-ключа не реализована клиентом, поэтому ранний return регистрации не означает сбой существующей функции смены. Старая история, системные карточки и группы не становятся зашифрованными. Retention после logout сохраняет ключи/черновики с разделением аккаунтов. Скриншоты и копирование текста остаются доступны. Эти свойства не объявляются устранёнными. Двухустройственное восстановление/сетевая гонка требуют отдельного QA. Пользователь уже подтвердил читаемый входящий push beta13.
