# PulsePath UI Beta 1.16.9-ui-beta.15+117

## Что доступно

Настройки → Приватность → «Проверка Signal · эксперимент»: локальные тестовые сообщения Алисы и Боба, native libsignal 9.0.0, шифрование, ответ с обновлением состояния сессии, повтор отправки сохранённым пакетом, отказ при подмене и повторное чтение после открытия хранилища. Отдельный флаг E2EE_SIGNAL_TEST=true не включает Signal в обычных чатах. Никаких запросов к серверу в диагностике нет; она использует отдельные синтетические идентичности и базы.

## Технические свойства

Callbacks с сериализацией state, pins на устройство с запретом молчаливой замены, учёт использованных PQ prekeys, транзакции SQLite с synchronous=EXTRA и secure_delete=ON. Шифрование state и inbox/outbox/archive локальным случайным ключом из защищённого хранилища. История вынесена из snapshot в отдельные аутентифицированные записи. Выходной шифропакет выдаётся после commit; повтор использует уже сохранённый пакет. JSON-порядок ключей не влияет на повтор. Состояние live ratchet нельзя восстанавливать из облачного snapshot; архив и повторное подключение устройства потребуют отдельного пути.

## Границы выпуска

Это промежуточная экспериментальная версия для удалённой загрузки по запросу пользователя. Обычные личные чаты сохраняют схему E2EE beta14 с постоянным ключом. Серверный v2-протокол, автоматический переход, вложения, группы, связывание устройств и восстановление Signal-архива ещё не реализованы. Выпуск не означает готовность защиты уровня WhatsApp. Существующие сообщения, аккаунты и ключи не очищаются и не перешифровываются. Данные диагностических баз не относятся к настоящей переписке.
