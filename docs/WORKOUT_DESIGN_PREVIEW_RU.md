# Тестовый дизайн тренировок — 14.11.2026

Локальная сборка **1.16.15-design.1+124** для телефона. Публичный релиз и изменение серверной схемы не выполнялись. Рабочая ветка: `codex/workout-redesign`, основа `7f782f7`.

## Что изменено

- Единая спокойная зелёная палитра, типографика и формы элементов. Общая тема сохраняет светлый/тёмный режим; отдельные экраны подготовки, планирования и техники используют согласованные поверхности и акценты.
- Подготовка: компактный выбор активности, понятные карточки техники и свободной тренировки, параметры записи отдельно, закреплённая кнопка старта. Значок соответствует выбранной активности.
- Конструктор: один возврат закрывает редактор вместо промежуточного экрана, сохранение называется «Сохранить план маршрута», рисование доступно из панели карты. Геометрический редактор открывает параметры сохранения непосредственно с карты.
- Гараж: отдельные карточки с пробегом и временем, явный выбор основной техники, дополнительные действия в меню. Форма добавления по умолчанию свёрнута. Подсказки обслуживания переносятся на несколько строк.
- Совместная тренировка: компактное описание, объяснение отдельной записи каждого участника, состояние ожидающего отправки итога с возможностью повтора.

## Исправления аудита

- R1/R2/R4: найденный черновик защищён от записи пустого состояния; начало заново требует подтверждения; ошибка локальной записи блокирует выход с неподтверждённым обещанием сохранения.
- R3: копия дорожного плана сохраняет опорные точки и расчётное время. Показатели записанной тренировки в план не переносятся.
- G1/G2: подтверждённые изменения гаража записываются в постоянный кэш, включая основной велосипед и удаление техники. Сохранение оборудования и прежнего пробега тоже обновляет кэш.
- G3: неудачная очистка ссылки фотографии останавливает удаление файла; пустой ответ обновления не считается успехом.
- J1/J2: отправка прогресса упорядочена; незавершающий запрос содержит серверное условие против отката `finished`; полный итог сохраняется до отправки и повторяется после восстановления. Устаревший контроллер не перезаписывает подтверждённый финиш меньшими показателями.
- A03: сеть вынесена из очереди локального сохранения истории; поздний ответ не должен отменять новые правки или локальное удаление.
- В диалоге восстановления короткая запись показывается в секундах вместо «0 мин».
