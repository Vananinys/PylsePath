# UI Beta: заезд от приглашения до результата

Контрольная точка до работы:12f8b93. Пользователь поручил выполнить шесть предложенных улучшений в отдельной UI Beta.

1. Разовая поездка отдельно от постоянного клуба; новая поездка с новым подтверждением. Исправить обнаруженное повторное использование комнаты организатора сервером.
2. Список приглашений и участников с реальными состояниями, отказом и отменой.
3. Единая подготовка: активность, транспорт, маршрут, участники; дополнительные настройки сворачиваются.
4. Сохранение личной тренировки отдельно от завершения участия; выход организатора сохраняет поездку остальным, результаты доступны после сохранения.
5. Главная клуба с ближайшим событием, непрочитанными сообщениями и серверными уведомлениями с режимами Все/Только приглашения/Выключены.
6. Понятные названия действий; целевые проверки UI, серверных прав и повторов, отдельный подписанный выпуск/каталог/push/установка без очистки данных.

Не менять роли обычных пользователей, не расширять доступ к координатам и не завершать чужую запись.
