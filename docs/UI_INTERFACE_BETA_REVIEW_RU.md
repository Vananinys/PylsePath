# Ревизия интерфейса и отдельная PulsePath UI Beta

31.10.2026. Контрольный снимок до изменений: `ed34890`; отдельная ветка `codex/interface-beta`. Пользователь явно выбрал приложение, устанавливаемое рядом с обычным PulsePath. Версия исходников: `1.13.0-ui-beta.1+84`.

## Объём и доказательства

Статический индекс построен для всех 48 файлов `lib/screens` и дополнительных UI-компонентов: 157 исходников, 261 вхождение конструкций экранов/диалогов/меню. Число вхождений не равно числу уникальных экранов. Файловый реестр с раздельными статусами — `UI_AUDIT_INVENTORY.csv`; список всех экранных файлов — `UI_SCREEN_COVERAGE_RU.md`. Полный локальный индекс и исходные наблюдения — `audit/2026-10-31/interface-beta/source-inventory.*`.

Проверены общие правила оформления, точки входа/названия, меню, настройки, карта/подготовка/запись, маршруты/места/офлайн, история/результаты, профиль/оформление, общение/медиа, группы/события, активность/гараж и служебные роли в объёме статического анализа и соответствующих автоматизированных проверок. Не утверждается физический обход всех серверных и ролевых состояний: для него нужны реальные сеансы и действия пользователей. Матрица не заменяет эти проверки зелёными отметками.

## Исправления

1. **Оформление:** ранее `ThemeMode.light` принудительно задавал светлую тему. Добавлены `AppAppearance`, системный режим по умолчанию, локальное сохранение и переключатель Настройки → Внешний вид → Тема приложения. Фоны, поля, карточки, уведомления и разделители используют светлую/тёмную палитру.
2. **Контраст:** адаптированы фиксированные нейтральные цвета в истории, профилях, чате/комментариях/ленте, поиске карты, предзапуске, маршрутах, выборе транспорта, офлайн-картах, уведомлениях, лаборатории и связанных компонентах. Тёмные поверхности видеоплееров, фотографии, брендовые блоки и смысловые цвета карт не инвертируются автоматически. Контраст базовых пар текста/фона проверен численно.
3. **Меню:** существующие callbacks и видимость модулей сохранены. Добавлены поиск по названиям/подписям и группы «Маршруты и места», «Моя активность», «Вместе», «Профиль и приложение». Неверное обещание скачивания области в пункте офлайн-карт заменено на проверку карт.
4. **Поиск настроек:** добавлены слова задач («голос», «фон», «тёмная», «обновления» и другие), чтобы пользователь находил раздел без знания его внутреннего названия.
5. **Маршрут:** карточки показателей адаптируются к ширине/масштабу текста. Неизвестные время и расстояние обозначены «Нет данных»; значения больше не ужимаются FittedBox в карточках статистики. Кнопки сохранения/публикации маршрута получили подсказки.
6. **Подготовка тренировки:** увеличены минимальные области выбора активности/автопаузы, высота списка пеших активностей учитывает системный шрифт; фоны и подписи адаптированы к теме.
7. **Места:** длинное пояснение и результаты размещены в прокручиваемой области, включая 320 px/200% текст. Кнопка «Найти через Overpass» переименована в понятное действие «Найти места по маршруту»; сведения об источнике и передаче геометрии сохранены.
8. **Ошибки и восстановление:** в профиле появляется явная карточка неполностью прочитанной истории, предупреждение о неполной статистике и повторная загрузка. Оригинал сохраняется прежним механизмом. В сообщениях истории/загрузки карты техническое исключение заменено объяснением следующего действия.
9. **Доступность:** 15 обычных IconButton без tooltip получили названия действий; итоговый статический поиск таких вызовов вернул 0. Это не утверждение полного аудита TalkBack и всех нестандартных жестов.

## Изоляция тестового приложения

- Имя: **PulsePath UI Beta**. Android package: `com.pulsepath.app`; обычная версия: `com.example.pulsepath`. Используется уже зарегистрированный второй клиент Firebase из действующего google-services.json.
- Сборка: `flutter build apk --release --dart-define=UI_BETA=true`. Dart и Gradle получают идентичность из одного флага; локальные файлы, сессия и настройки раздельные.
- Каталог: `app_ui_beta_releases`, отдельная очередь и worker `send-ui-beta-release-push`, тема FCM `pulsepath_ui_beta_updates`. Стабильный/обычный beta-каталоги не читаются UI Beta; обычные приложения не читают новый каталог. Переключатель стабильного канала в UI Beta не предлагается.
- Существующий облачный аккаунт и его сохранённые данные **общие**. Это не отдельный тестовый сервер: действия с облачной тренировкой, сообщением или профилем выполняются для вошедшего пользователя. Не вести параллельную запись одного аккаунта в двух приложениях.
- Существующая email-ссылка `pulsepath://login-callback` совместима с обоими пакетами. Android может предложить выбрать приложение; для ссылки, запрошенной из UI Beta, выбрать UI Beta. Отдельная схема потребовала бы изменения настроек Auth redirect и обратной совместимости; в этой задаче схема не менялась. Парольный вход и локальные PKCE-сессии раздельные.
- Публичный доступ к новому каталогу — только чтение опубликованных строк; клиентские записи, доступ к очереди и вызов claim запрещены. RLS и эти привилегии проверены запросом. Cron повторов активен. Старый worker/триггеры не изменялись.

## Проверки

- Общий Flutter-прогон текущих исходников: **634 passed** (`tests-complete.log`).
- Отдельный прогон с `UI_BETA=true`, экспортом реальных виджетов входа/маршрута и проверкой обеих тем: **12 passed** (`tests-beta-capture-final.log`). Снимки просмотрены; иконки и шрифты загружены.
- 49 изменённых Dart-исходников: ошибок/предупреждений анализатора нет, 75 стилевых info (`analyze-targeted.log`). Полный анализ lib ранее отметил два существовавших предупреждения вне изменённой области (weather_service, rider_marker); не удалялись ради косметического отчёта.
- В первом общем прогоне обнаружены три старые несогласованности тестов; все три воспроизвелись на снимке `ed34890` в отдельной worktree. Проверки чата усилены: после смены владельца требуется исключение и проверяется сохранность сообщений при возврате владельца. Профиль теперь явно показывает корректное восстановление истории; проверка сохраняет требования к повреждённому оригиналу и резервной копии.
- В CI добавлены проверки интерфейса/тем, конфигураций Firebase для обоих Android package и отдельного beta-флага.

## Границы проверки и продолжение

Эмулятор не запустился: отсутствует драйвер аппаратного ускорения. Настройки ОС/гипервизора не менялись. В ходе работы появился один физический телефон; состояние установки/запуска и публикации фиксируется отдельной итоговой записью журнала после проверки APK.

Тесты виджетов/контраст и сборка не доказывают полевой GPS, TalkBack на реальном телефоне, длительный фон, расход батареи или взаимодействие двух аккаунтов. Эти ограничения не закрываются заглушками и не меняют прежних ограничений офлайн-маршрутизатора/источников мест. Следующий пользовательский шаг после установки — войти в отдельную UI Beta и пройти реальные сценарии из `UI_CLARITY_PLAN_RU.md`; стабильная версия остаётся рядом для сравнения.
