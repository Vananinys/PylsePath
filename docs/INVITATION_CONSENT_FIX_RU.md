# Добровольное принятие приглашения — UI Beta4

31.10.2026, source `846b7df5efc29e1c39f717a159c0bf10f698a5eb`.

Пользователь сообщил, что после приглашения человек уже показан участником, а у отправителя сразу открывается подготовка. Проверены текущие серверные функции и состояние без вывода личных идентификаторов: у недавнего приглашения accepted_at отсутствовал, но получатель уже состоял в той же комнате до его отправки. Отправка group_send_invite пишет приглашение/сообщение, не добавляет членство. Второй причиной был прямой переход отправителя к подготовке сразу после отправки.

Исправления:

- Убрано автоматическое открытие подготовки сразу после отправки в личном чате. Показано «ожидаем, пока человек сам примет».
- В списке друзей участник старой комнаты явно обозначен как уже участвующий, повторная отправка ему отключена; сервис также отвергает такую отправку до RPC.
- Если из личного чата приглашён уже участвующий человек, предлагается новая поездка с явным подтверждением закрытия прежней комнаты. Старое членство не удаляется автоматически; личная запись не останавливается.
- Для новой поездки требуется новое принятие получателем. Переход организатора при реальном присоединении и переход получателя после его нажатия сохранены. Кнопка перехода из списка отправленных приглашений недоступна до появления принятого участника.
