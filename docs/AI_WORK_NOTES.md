# Рабочие заметки PulsePath

Краткий контекст для продолжения разработки. Факты из записей нужно сверять с текущим деревом. Новые записи добавляются в конец; секреты и персональные данные сюда не попадают.

## 2026-10-28 — Правила выпусков

- По прямому указанию пользователя скил дополнен правилом: беты только для совсем экспериментальных функций или объёмных изменений; обычные изменения выпускаются стабильно.
- Каждый выпуск приложения сопровождается опубликованным GitHub Release с версией, тегом, APK, описанием изменений и уведомлением о выпуске. Также соблюдаются правила каталога приложения и уведомлений из `docs/GIT_AND_RELEASES_RU.md`.
- Изменены инструкции; выпуск приложения в рамках этой задачи не выполнялся.

## 2026-10-28 — Скил и проектный журнал

- По просьбе пользователя дополнен существующий скил `pulsepath-flutter` в каталоге Codex `skills/pulsepath-flutter/SKILL.md`: добавлены чтение и ведение этого журнала, проверка актуальности документации и трактовка установки обновлений приложения на телефон.
- Правила пользователя: не удалять код и файлы без разрешения; при подключённом телефоне устанавливать обновления приложения после изменений приложения.
- Архитектурный контекст находится в `PROJECT_STRUCTURE.md`; перед изменениями нужно сверять его с исходниками.
- Обнаруженное препятствие: `README.md` ссылается на `run_android.ps1` и `docs/APP_UPDATES_RU.md`, однако при проверке в текущем рабочем дереве эти файлы отсутствовали. Команды из этих ссылок нельзя считать готовыми к запуску.
- При начальной проверке `git status --short` рабочее дерево было чистым. В этой задаче меняются только инструкции и заметки; сборка приложения и установка на телефон не выполнялись.

## 2026-10-28 — Исправления карты по фото и видео, 1.12.22

- Продолжение от опубликованного 1.12.21 (88a2025): сохранены его исправления масштаба отпечатков, дистанции сохранённого маршрута и поиска. Дополнительно исправлен поиск при оставшемся флаге предзапуска, распределение места погоды и шагомера, отступ копирайта от нижней панели.
- Фаза короткого шлейфа сохраняется при обрезке старых точек. В оформлении добавлены независимые рисунки и выключатели для друзей и собственной позиции вне тренировки; оформление остаётся локальным, правила видимости GPS не расширены. Светлая подложка под отпечатками не используется.
- Миниатюры на локальной и общей карте уменьшены до 24 логических пикселей, не поворачиваются вместе с картой. Выбор материала в редакторе не приближает и не сдвигает карту всего трека.
- Камера следования учитывает высоту панели тренировки. Видео 8.776 с прочитано через OpenCV; изучены 12 кадров. Это не физическая проверка датчиков.
- Перед выпуском: 23 целевые проверки прошли; анализ затронутых файлов завершился без ошибок и предупреждений (остались стилевые info). Release APK собирается. ADB не видит устройств. Публикация стабильной версии 1.12.22+76 и проверка очереди push выполняются в этой задаче; итог уточняется следующей записью.
