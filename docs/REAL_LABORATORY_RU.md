# Лаборатория на рабочей карте — 01.11.2026

## Что изменено

В обычном приложении лаборатория подключает управляемый источник наблюдений к существующему `MapNavigationController`. Входные координаты помечены `Position.isMocked=true`. Меняется источник координат внутри PulsePath, а не системная геолокация телефона. Обработчик GPS, фильтр точек, расчёт расстояния, пауза, навигационный прогресс, отклонение и построение маршрута остаются рабочими.

Прежний `DeveloperLabScreen` сохранён в исходниках: он не используется входом лаборатории основной карты. Новый вход передаётся из карты через SettingsScreen. Переработка отдельной UI Beta не переносилась: основа ветки — `ed34890`, обычное приложение после исправления записи с выключенным экраном.

## Как использовать

1. Войти владельцем или пользователем с серверным разрешением лаборатории. Открыть Настройки, семь раз нажать заголовок, выбрать «Для разработчика». Серверный `my_lab_access` проверяется снова перед включением; новых прав пользователям не выдаётся.
2. Настоящую активную/приостановленную тренировку сначала завершить. Если есть настоящий незавершённый черновик, сначала восстановить или завершить его. Лаборатория не смешивается с ним.
3. На основной карте появляется панель «ЛАБОРАТОРИЯ · тестовый GPS». Раскрыть её стрелкой. Заголовок можно перетаскивать вниз, освобождая обычные элементы карты; панель прокручивается и сворачивается.
4. Для другой стартовой позиции сдвинуть карту и нажать «Перенести в центр карты» до начала тестовой записи. Выбрать скорость и курс; «Ехать» двигает собственный маркер с учётом прошедшего времени, «Стоять» прекращает движение, но продолжает подавать неподвижные наблюдения.
5. Обычными кнопками построить/открыть маршрут и запустить навигацию. «Ехать по маршруту» задаёт последовательность входных координат вдоль выбранной полилинии. Смена курса прекращает следование и позволяет уйти в сторону. Готовое состояние «поворот» или «отклонение» лаборатория не выставляет.
6. Обычной кнопкой начать тренировку; проверить трек, расстояние, скорость, паузу, продолжение, интервалы и финиш. «Стоять» в лаборатории и пауза тренировки — разные действия, поэтому можно проверить автопаузу и движение во время ручной паузы.
7. Для ухудшения GPS изменить погрешность. Для потери наблюдений выключить их подачу: маркер перестаёт получать координаты, обычный контроль свежести определяет потерю сигнала через свой порог. Внутреннее движение продолжается, новые наблюдения после включения отражают новую позицию. Для офлайн-проверки действительно отключить сеть телефона; выключателя с выдуманным результатом запроса нет.
8. Завершить тренировку обычной кнопкой сохранения. «Записи / JSON» показывает реальные сохранённые метрики и позволяет скопировать полную запись с маркировкой `source=laboratory`. Локальная контрольная точка записывается во время тестовой поездки. После перезапуска заново включить лабораторию → «Восстановить тест»: восстановление на паузе, затем обычное продолжение/сохранение.
9. После завершения тестовой записи нажать «Вернуть настоящий GPS». Навигация тестового сценария прекращается, свежесть и привязка к позиции сбрасываются, снова запускается обычный GPS. Уход из лаборатории с незавершённой записью отклоняется. Приложение не остаётся в тестовом режиме после перезапуска.

## Изоляция и границы

- Синтетические позиции не публикуются в `live_positions` и групповой прогресс. Нативная фоновая трансляция, если пользователь включил её отдельно, продолжает работать с настоящим системным GPS; лаборатория не изменяет его.
- Тестовая запись использует отдельные локальные ключи аккаунта `laboratory_checkpoint_*`, `laboratory_result_*`, `laboratory_closed_*`. Завершение не вызывает обычный репозиторий истории, облачный retry, начисление наград или учёт износа техники. Прежние данные/файлы не удаляются. Закрытые контрольные точки сохраняются, но не предлагаются для восстановления.
- Для тестовой записи нельзя выбрать настоящую группу. Её нельзя выдавать за реальный совместный заезд или проверку Realtime двух устройств. Проверка общения и серверных ролей требует настоящих аккаунтов/устройств либо отдельного тестового окружения, которого эта работа не создаёт.
- Сеть, карты, поиск, маршрутизация, голос и обычные разделы приложения настоящие. Действия в событиях и чатах действуют на сервере по прежним правам; весь сервер не превращается в песочницу. Внешних сервисов, платных API и новых серверных привилегий не добавляли.
- Физические шаги не выводятся из управляемого движения, датчик шагов не подменяется. Тестовый GPS не подтверждает точность спутников, фон Android, расход батареи или физическое воспроизведение голоса. При уходе приложения в фон управляемое движение останавливается; кнопка продолжения движения нужна после возврата. Промежуток приостановленного процесса не превращается в скачок координат.
- При смене аккаунта входные наблюдения не принимаются, источник останавливается. Обычные RLS и административные права не расширяются.
- Автономного дорожного пересчёта и нового источника офлайн-тайлов нет. Лаборатория выявляет существующие ограничения, не скрывает их.

- Финальный объединённый прогон:46/46 — рабочая лаборатория, screen-off recording, location recovery, draft store, navigation package, прежний экран лаборатории, live location. Это целевой набор, не полный набор проекта.
- Анализ затронутых исходников: без ошибок и предупреждений, стилевые info. В процессе исправлены фикстура HTTP-ответа, неверное именованное обращение к positional API и подтверждённое переполнение панели при 200%. Фильтр неправдоподобных GPS-скачков не ослаблялся ради теста; вместо мгновенного переноса тест использует реальное движение по времени.
- ADB при начале/после тестов: 0 устройств. Физическая проверка переключения GPS, TTS, экранов и блокировки не выполнена. Требуется подключённый разблокированный телефон с разрешённой отладкой; обновлять только поверх обычного пакета без очистки/понижения. Отдельную UI Beta не заменять.
