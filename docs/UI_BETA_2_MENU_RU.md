# UI Beta 2: внутренние экраны разделов

31.10.2026. Продолжение отдельной UI Beta по запросу пользователя: переработать внутренности меню, прежде всего события и совместную поездку, установить обновление на телефон. Предыдущая версия сохранена в Git (`fbab3db`) и опубликованном APK 84. Ветка — `codex/interface-beta`, новая версия — `1.13.0-ui-beta.2+85`.

## Изменения

- **События и челленджи:** вводный блок с фактическим опытом/участием, фильтры «Доступные / Моё участие / Завершённые», карточки с типом, статусом, сроком, условиями, наградой и следующим действием. Будущие события не предлагают вступление раньше начала. Завершённые и уже награждённые не предлагают повторный claim. Челленджи по тренировкам не показывают ненужный опрос. Ответы и завершение доступны прежним ролям через меню карточки.
- **Формы:** оценки опроса выбираются из 1–5; пояснение о добровольности и приватности находится внутри опроса. Ошибки создания/UUID/оценок/числовых полей показываются до закрытия формы, введённые значения сохраняются. Существующие серверные команды и правила не заменяются локальной имитацией.
- **Совместная поездка:** отдельный понятный вход с созданием/кодом и раскрываемой инструкцией. В группе — роль, готовность, состояние личной записи, приглашение, разделы сбора/людей/связи в дороге. Карта раскрывается отдельно; выбор места возвращает к ней и показывает точку. Контент прокручивается целиком, а переход к подготовке собственной тренировки закреплён внизу. Участники при крупном тексте показаны в один столбец. Создание группы и кнопка подготовки по-прежнему не запускают запись автоматически.
- **Сохранённые маршруты:** вводный блок с количеством путей и объяснением открытия/создания перед существующими поиском и фильтрами.
- **Мои места:** вводный блок объясняет построение маршрута и локальное хранение; заголовок и список помещены в прокручиваемую структуру для узкого экрана/крупного текста.
- Общие компоненты `SectionIntro`, `SectionStep`, `EventOverviewCard` используют действующую светлую/тёмную палитру. Данные и функции не удалялись; серверная схема событий/групп и права не менялись.
